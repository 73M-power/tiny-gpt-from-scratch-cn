语言模型的任务，是根据已经出现的文字预测下一个文字。
模型看到“春天来了”，会尝试判断后面更可能出现“花开了”还是“机器飞翔”。
训练不是把答案直接写进程序，而是不断比较预测和真实答案，再调整参数。
参数是模型内部可以学习的数字。很多参数共同决定模型如何处理输入。

文字进入模型以前，需要先变成整数。这个过程叫作分词。
为了让第一个实验足够透明，我们把每个汉字、标点和换行都当成一个 token。
token 是模型读取和预测的基本单位。
词表记录 token 和整数编号之间的对应关系。
编码把文字转换成编号，解码把编号转换回文字。

一个训练样本包含输入和目标。
输入是“语言模型”，目标向右移动一个位置，变成“言模型的”。
因此，输入的每个位置都在练习预测它后面的字符。
这种训练目标叫作 next-token prediction，也就是下一个 token 预测。

embedding 把离散的 token 编号变成连续向量。
向量中的每个数字本身没有固定的人类解释，但它们共同表示模型学到的特征。
位置 embedding 告诉模型每个 token 位于序列中的什么地方。
token embedding 和位置 embedding 相加，形成 Transformer 的初始输入。

注意力让序列中的一个位置读取其他位置的信息。
query 表示当前位置想寻找什么，key 表示每个位置能够提供什么线索，value 表示实际传递的信息。
query 和 key 的相似度决定注意力权重，权重再对 value 进行加权求和。
多头注意力并行执行多组注意力，让不同的头学习不同关系。

语言模型生成文字时不能看到未来。
因果遮罩把未来位置挡住，使当前位置只能关注自己和更早的 token。
如果训练时能够偷看未来，模型虽然容易得到低损失，却无法真正学会生成。

Transformer block 由注意力、前馈网络、残差连接和归一化组成。
注意力负责在不同位置之间交换信息。
前馈网络分别处理每个位置，对特征进行非线性变换。
残差连接让信息和梯度更容易穿过许多层。
LayerNorm 让中间数值保持在更稳定的范围。

模型最后为词表中的每个 token 输出一个分数，这些分数叫作 logits。
softmax 把 logits 转换成概率分布。
交叉熵衡量模型给真实下一个 token 的概率是否足够高。
真实答案的概率越高，交叉熵通常越低。

反向传播使用微积分的链式法则计算每个参数对损失的影响。
梯度指出参数朝哪个方向变化会让损失增大。
优化器沿着相反方向更新参数，从而逐步减小损失。
学习率控制每一步更新的幅度，太大可能不稳定，太小则学习缓慢。

训练循环不断重复几个动作：抽取批次、执行前向传播、计算损失、执行反向传播、更新参数。
batch 是一次并行处理的多个训练片段。
上下文窗口限制模型一次最多能够读取多少 token。
训练步数表示优化器完成了多少次参数更新。

训练损失反映模型对训练数据的拟合程度。
验证损失使用没有参与参数更新的数据，可以帮助观察模型是否具有泛化能力。
训练损失下降而验证损失上升，通常意味着出现了过拟合。
小语料上的 Tiny GPT 主要用于理解机制，不代表真实大模型的语言能力。

推理阶段不再计算梯度，也不更新参数。
模型读取提示词，预测下一个 token，把选中的 token 接回输入，然后继续预测。
温度控制概率分布的尖锐程度。温度较低时结果更确定，温度较高时结果更多样。
top-k 采样只保留概率最高的一部分候选，可以减少非常离谱的输出。

checkpoint 保存模型参数、模型配置和词表。
加载 checkpoint 后，可以恢复同一个模型并继续生成文字。
如果只保存参数而忘记词表，整数编号就无法正确还原成原来的 token。

大语言模型与这个小模型共享许多基础机制。
它们都使用 token、embedding、注意力、前馈网络、交叉熵和梯度下降。
主要差别在于参数规模、训练数据、工程优化和训练目标的丰富程度。
先看懂一个小模型的完整闭环，再学习大型模型会容易很多。

清晨，阳光照进书房。学习者打开电脑，准备观察模型如何从文字中发现规律。
第一步是读取语料，第二步是建立词表，第三步是构造输入和目标。
模型起初完全随机，它生成的句子通常没有意义。
经过一次次训练，常见的字符组合逐渐获得更高概率。
损失曲线下降，说明模型的预测正在接近训练语料。

统计关系并不等于真正理解世界，这一点十分重要。

使用模型时需要验证重要信息，并认识到训练数据和目标带来的局限。

训练循环抽取一批文本片段，计算预测，比较答案，然后更新参数。
